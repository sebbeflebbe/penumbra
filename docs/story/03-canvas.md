# Chapter 03 — Canvas and crypto

Cards are widgets so they exist in the semantics tree. A list provides document order: Index rows are focusable, Up and Down move selection without stealing the sheet’s arrow-nudge, and Move announces the card numeral then returns focus to the handle. Arrow keys or a named Move handle reposition the focused card. Human slips can be edited and deleted; deleting a parent also removes its echo.

Payloads are AES-256-GCM. Tests assert stored ciphertext does not contain plaintext, and that a second user cannot read a board (RLS contract). Restricted boards refuse writes, including delete (Art. 18).
