# ADR-004 — Content-Security-Policy on Flutter web

Status: accepted
Date: 2026-08-31

Flutter CanvasKit/Skwasm needs wasm, workers, blob URLs, and unsafe-eval-adjacent patterns. A strict CSP that works for a classic HTML app will break the runtime.

We ship HSTS, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, and the strictest CSP that still boots Flutter, and we document the gap instead of shipping a lying header.
